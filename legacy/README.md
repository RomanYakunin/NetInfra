# legacy/ — вышедший из употребления код

Файлы не подключены ни к одной странице и оставлены только на случай,
если из них понадобится что-то достать. Каталог можно удалить.

| Файл | Почему здесь |
|---|---|
| `import.php` | Отдельная страница импорта оборудования из Excel. Требует PhpSpreadsheet (`\PhpSpreadsheet\src\PhpSpreadsheet\IOFactory`), а библиотека из проекта удалена — каталога `vendor/` нет, поэтому страница падала бы при первой же загрузке файла. Задачу решает `modules/import_nodes/`. |
| `autoload.php` | Автозагрузчик классов, нужен был только `import.php`. Больше ничем не подключается. |
