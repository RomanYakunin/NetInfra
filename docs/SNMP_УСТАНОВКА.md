# Как включить SNMP на другом компьютере предприятия

Проект использует **встроенное расширение PHP `snmp`**, а не внешние утилиты.
Поэтому ничего скачивать и устанавливать не нужно — расширение уже входит в
поставку OpenServer. Нужно только включить его и перезапустить сервер.

---

## Шаг 1. Проверить, включено ли расширение

Положите в корень сайта файл `snmp_check.php`:

```php
<?php
header('Content-Type: text/plain; charset=utf-8');
echo 'PHP: ' . PHP_VERSION . PHP_EOL;
echo 'php.ini: ' . php_ini_loaded_file() . PHP_EOL;
echo 'Расширение snmp: ' . (extension_loaded('snmp') ? 'ВКЛЮЧЕНО' : 'ВЫКЛЮЧЕНО') . PHP_EOL;
```

Откройте его в браузере. Если написано **ВКЛЮЧЕНО** — всё готово, переходите
к шагу 4. Если **ВЫКЛЮЧЕНО** — шаг 2.

Файл после проверки удалите.

---

## Шаг 2. Включить расширение

1. Посмотрите в выводе строку `php.ini:` — это путь к нужному файлу,
   например `C:\OSPanel\modules\php\PHP_7.4\php.ini`.
2. Убедитесь, что рядом есть сама библиотека:
   `C:\OSPanel\modules\php\PHP_7.4\ext\php_snmp.dll`
   (каталог `ext` находится рядом с `php.ini`).
3. Откройте `php.ini` в текстовом редакторе, найдите строку:

   ```ini
   ;extension = snmp
   ```

4. Уберите точку с запятой в начале:

   ```ini
   extension  = snmp
   ```

5. Сохраните файл.

**Если строки `;extension = snmp` нет вообще** — допишите в конец списка
расширений строку `extension = snmp`.

---

## Шаг 3. Перезапустить сервер

Важно: OpenServer читает `php.ini` только при запуске.

- Нажмите на значок OpenServer в трее правой кнопкой → **Перезапустить**.
- Обычной перезагрузки страницы в браузере **недостаточно**.

После перезапуска снова откройте `snmp_check.php` — должно быть **ВКЛЮЧЕНО**.

### Если после перезапуска снова ВЫКЛЮЧЕНО

Некоторые сборки OpenServer пересобирают `php.ini` из шаблона и затирают
правку. Тогда правьте шаблон:

```
C:\OSPanel\userdata\config\PHP_7.4_php.ini
```

(имя файла соответствует вашей версии PHP), там та же строка
`;extension = snmp`. После правки — перезапуск OpenServer.

---

## Шаг 4. Проверить работу опроса

1. Откройте любое оборудование → **Подробнее** → кнопка **📡 SNMP-запросы**
   (кнопка появляется только если у оборудования указан IP-адрес).
2. Выберите запрос «Системное имя (sysName)», community — как настроено на
   оборудовании (часто `public`), нажмите **Подгрузить**.

Возможные сообщения:

| Сообщение | Что делать |
|---|---|
| Данные в таблице | Всё работает |
| «Устройство … не ответило» | Проверьте доступность IP (`ping`), включён ли SNMP на оборудовании, разрешён ли IP сервера в ACL |
| «Community-строка не подходит» | Уточните community на оборудовании |
| «Логин или пароль не подходят (SNMPv3)» | Введите правильные логин/пароль в появившемся блоке и нажмите **Вперёд** |
| «Утилита Net-SNMP не найдена» | Расширение не включилось — вернитесь к шагу 2 |

---

## Что нужно со стороны сетевого оборудования

Опрос не заработает, пока на самом коммутаторе не настроено:

1. **Включён SNMP** (обычно v2c).
2. **Задана community-строка** на чтение (read-only).
3. **Разрешён IP сервера** в списке доступа SNMP (ACL).

Пример для Cisco:

```
snmp-server community ВАША_СТРОКА RO 10
access-list 10 permit IP_СЕРВЕРА
```

Без этого сервер будет получать таймаут независимо от настроек PHP.

---

## Про SNMPv3 и учётные данные

- **SNMPv2c логин и пароль не использует** — только community-строку.
- **SNMPv3** использует имя пользователя и пароль. Проект берёт их с сервера
  автоматически: сначала из `equipment_credentials` (учётные данные
  конкретного устройства), затем из `vendor_defaults` (стандартные для
  производителя). Пароль при этом в браузер не передаётся.
- Пароль SNMPv3 по стандарту должен быть **не короче 8 символов**. Пароли от
  SSH часто короче — тогда система попросит ввести подходящие вручную.

---

## Если расширения в сборке нет

Редкий случай: в каталоге `ext` отсутствует `php_snmp.dll`. Тогда нужны
внешние утилиты Net-SNMP — проект их поддерживает как запасной вариант:

1. На компьютере с интернетом скачать установщик Net-SNMP для Windows
   с https://sourceforge.net/projects/net-snmp/ и перенести на сервер.
2. Установить (по умолчанию утилиты попадают в `C:\usr\bin\`).
3. Проверить в командной строке:

   ```
   C:\usr\bin\snmpget.exe -v2c -c public 10.0.0.1 1.3.6.1.2.1.1.5.0
   ```

4. Если путь установки другой — поправить константы `SNMPGET_PATH` и
   `SNMPWALK_PATH` в файле `config/snmp_oids.php`.

Проект сам определит, что расширения нет, и переключится на утилиты.
